# Eve agent workspace visibility

หน้า **วิเคราะห์ข้อมูล** แสดงทีม AI Commerce ให้ผู้ใช้เห็นเสมอ เพื่อแยกความหมายระหว่าง “มีฟีเจอร์อยู่ในระบบ” กับ “ได้รับอนุญาตให้เรียกโมเดลแล้ว”

## สิ่งที่ผู้ใช้เห็น

- `Commerce Lead` รับคำถาม แบ่งงาน และรวมคำตอบ
- `Marketing Analysis` วิเคราะห์โอกาสด้านยอดขายและการโปรโมต
- `Inventory Analysis` วิเคราะห์สต๊อกและความเสี่ยงสินค้าขาด
- สถานะที่อ่านง่าย ได้แก่ `ยังไม่เปิดใช้งาน`, `กำลังเชื่อมระบบ` หรือ `เตรียมช่องสนทนา`

## หลักความปลอดภัย

- หน้าเว็บไม่รับ URL, signing key หรือ secret ของ Eve ไปแสดงแก่ผู้ใช้
- หน้าจอยังไม่อ้างว่า `พร้อมใช้งาน` แม้ tenant อยู่ใน allowlist และเชื่อม runtime แล้ว จนกว่าจะมีช่องสนทนาแบบ tenant-scoped ที่ทำงานครบเส้นทาง
- Dynamic routing แสดงเป็นช่วงรออนุมัติจนกว่าจะตรวจ policy ของ tenant ใน Commerce Core
- ระหว่างที่ Live AI ปิด ผู้ใช้ยังใช้การตรวจข้อมูลแบบ deterministic เดิมได้

การเพิ่มหน้าจอนี้ยังไม่เปิด Live AI และยังไม่เปลี่ยนค่าบน Render หรือ Vercel
